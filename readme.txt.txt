Dear students,

Here are the project requirements:-

1. Team Composition
Students will work in groups of 3. Each group must form its own team before starting the project.

2. Project Topic
Each team may choose any topic of interest to build their project on.

3. Technical Requirement
The project must use a minimum of two ML algorithms taught in the course. Teams should be able to justify why these algorithms were chosen for their use case.

4. Submission Requirements
Each team must submit:

GitHub Repository — must be public, containing all code and work done for the project.
Project Report, which must include:
Project name, title, and a brief abstract/description
What the project is about
What has been built (approach, methodology, features)
Metrics used to evaluate the model(s)
How model accuracy/performance was improved (experiments, tuning, iterations)
Individual contributions — the specific contribution of each team member must be explicitly mentioned
5. Deadlines

Project Title & Abstract Submission: On or before 30th September (in the Google Sheet shared previously)
Final Project Deadline: 4th October
